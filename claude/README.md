# claude/

Personal Claude Code configuration for day-to-day engineering work.

## Files

- **`CLAUDE.md`** — main config loaded by Claude Code automatically
- **`settings.local.json.example`** — template for environment variables (API tokens, internal URLs)

## Setup

1. Copy `CLAUDE.md` to `~/.claude/CLAUDE.md`
2. Copy `settings.local.json.example` to `~/.claude/settings.local.json` and fill in your values
