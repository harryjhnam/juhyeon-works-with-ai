# juhyeon-works-with-ai

A personal collection of prompts, configs, and workflows I use to work with AI — not to chase new tools, but to solve problems faster.

---

## Philosophy

I think of AI as a force multiplier, not a magic wand. Before reaching for a new model or framework, I ask: *what's the actual problem, and is this the right tool for it?*

That mindset shapes how I build these workflows — each one exists because it solved a real friction I had, and I keep refining them as I learn.
